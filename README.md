The funniest famous last words, carved as a single tombstone epitaph of at most 150 characters. One original line: a man who lived by snoozing every warning, right up to the last one.

## Run

```sh
python3 main.py
```

This writes the epitaph to `/output/entry.txt` (one line, 67 characters, UTF-8), guarded to 1–150 characters and verified by reading the file back.
